# SCM630 开发实践 {#openharmony}

## 开发环境

本指南以 WSL Ubuntu 22.04 为开发环境, 开发环境配置请参考 [OpenHarmony下载及编译](../../嵌入式开发/操作系统/OpenHarmony/OpenHarmony源码下载与编译.md)

## 源码下载

源码请从[服务器文件](http://192.0.2.10:1024/chfs/shared/itx_share/11_%E9%A1%B9%E7%9B%AE%E6%96%87%E4%BB%B6/OpenHarmony-scm630/OpenHarmony_Release.tar.gz)中下载，服务器文件中配置了 git 信息，可以同步 SCM630L144 的代码。

## 解压

执行 `tar -xvf OpenHarmony_Release.tar.gz` 解压代码文件，执行时间较久。
执行完成解压之后需要使用 `git pull` 同步最新代码

## 编译

```bash

  standard
```

执行命令 `hb build -f` 进行编译，会生成配置文件，在没有删除命令 `rm out/scm630/scm630` 删除生成文件之前，可以执行命令 ` hb build -f --fast-rebuild=true ` 命令进行快速编译，不会生成配置文件，加快编译速度。

## 删除编译文件

执行命令 `rm out/scm630/scm630` 可删除编译生成的文件。
