可以看到**ttyUSB1-5**，在此设备上的模块配置串口是**ttyUBS3**
执行以下命令进行网络配置
```shell
busybox microcom /dev/ttyUSB3 -s115200

#AT双路拨号
AT+QCFG="nat",0
OK
AT+QCFG="multiusbnet",2
OK
//手动重启模块
AT+QCFG="5glan",1,1
OK
AT+CGDCONT=1,"Ethernet","apneth",,,,,,,,,,,,,,1,"01.A70002"
OK
AT+CGDCONT=2,"IP","apnip",,,,,,,,,,,,,,1,"01.A70002"
OK
AT+QNETDEVCTL=1,1,1
OK
AT+QNETDEVCTL=2,1,1
OK
//查询通过网络同步的最新时间计算出的当前本地时间。
AT+QLTS=2

```
