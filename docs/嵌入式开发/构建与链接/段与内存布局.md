# 段与内存布局 {#_1}

- **.text 段**
    - **作用**：存放程序的可执行代码（指令）。
    - **特点**：通常映射到 ROM 或闪存（只读），供处理器直接执行。
    - **必要性**：必须，程序的核心部分。
- **.data 段**
    - **作用**：存放已初始化的全局变量和静态变量（例如 int global = 42;）。
    - **特点**：初始值存储在 ROM，运行时复制到 RAM。
    - **必要性**：必须，用于存储有初始值的变量。
- **.bss 段**
    - **作用**：存放未初始化的全局变量和静态变量（例如 int global;）。
    - **特点**：不占用目标文件空间，运行时分配在 RAM 并清零。
    - **必要性**：必须，确保未初始化变量为 0。
- **.rodata 段**
    - **作用**：存放只读数据，例如字符串常量、const 变量。
    - **特点**：通常映射到 ROM，直接读取。
    - **必要性**：通常需要，用于存储常量数据。
- **.stack 段**
    - **作用**：为程序分配栈空间，用于函数调用和局部变量。
    - **特点**：分配在 RAM，栈顶地址由符号（如 _stack_top）定义。
    - **必要性**：必须，嵌入式系统中栈不可或缺。
